# Horizon Max FPS

## Version 0.5.0 — safety release

This version removes all rendering and frame-rate hooks. It does not hide the hand, remove visual elements, force a frame-rate limit, or execute code during frames or entity rendering.

Older versions could lower performance. For the best stock Horizon performance, remove Horizon Max FPS completely and restart Horizon.

## Why this project no longer promises 1000 FPS

A mod cannot guarantee a specific frame rate. Actual FPS depends on the CPU, GPU, resolution, render distance, world complexity, temperature, power limits, drivers, and Horizon's renderer. Raising a frame-rate cap does not create additional frames.

## Recommended recovery

1. Fully close Minecraft and Horizon.
2. Remove Horizon Max FPS from the launcher.
3. Restart the computer if the game was running at full GPU load.
4. Start Horizon without this mod and compare FPS in the same world, location, direction, resolution, and render distance.
